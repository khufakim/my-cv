Case study · Web

Khufa Academy — School Management System

Academic project · HTML, CSS, JavaScript, Bootstrap

Overview

A multi-page school management website that brings daily administration into a single, easy-to-scan dashboard. The goal was to practise real front-end structure: navigation, data-heavy layouts and responsive behaviour.

What it does

  • Manages student and teacher records in one place
  • Tracks classes, subjects and daily attendance
  • Organises examinations and publishes results
  • Keeps the same layout usable on desktop and mobile

Stack

HTMLCSSJavaScriptBootstrap

What I learned

How to structure a multi-page front end, keep a consistent visual system with Bootstrap, and handle interactive UI logic in plain JavaScript without over-engineering it.
Case study · Database

Hospital Patient Record System

Academic project · SQL, ERD, DFD, Database Design

Overview

A database project that models a hospital's patient journey — from registration and appointments to prescriptions, lab tests and billing. The design started on paper before any tables were created.

What it does

  • Patient, doctor and appointment records with linked tables
  • Prescriptions, admissions and laboratory test tracking
  • Billing records tied to each patient visit
  • ERD and DFD documentation created before implementation

Stack

SQLERDDFDDatabase Design

What I learned

How to translate requirements into a normalised schema, protect data integrity with keys and relationships, and communicate a system visually before writing a single query.
Case study · Machine learning

Cat vs Dog Image Classification

Academic project · Python, TensorFlow, Keras, CNN

Overview

A convolutional neural network trained to classify photos of cats and dogs — built as a hands-on introduction to the full deep-learning workflow, not just the model layer.

What it does

  • Preprocesses and augments an image dataset
  • Trains a CNN using TensorFlow and Keras
  • Evaluates accuracy on unseen images
  • Tests individual predictions to understand failure cases

Stack

PythonTensorFlowKerasCNN

What I learned

How training-data quality shapes results, what convolution and pooling layers actually do, and how to read accuracy and loss curves while tuning a model.
